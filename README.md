# PDF Transaction Extraction & Web UI

## Description
A full-stack solution to ingest, parse, translate and store 30 years of Tamil real-estate
transactions from a PDF into a PostgreSQL database, and present them in a searchable web UI.

## Steps to setup development

- Install the packages for node
```bash
npm install
```

- Run the frontend by moving in base directory

```bash
npm run dev
```

- Run the backend by moving to pdf-transaction-api/

- Install the packages for node
```bash
npm install
```

```bash
npm run start:dev
```

Start the app on 
```
http://localhost:5173/
```
Default Login creds
```
username - admin
password - admin123
```

## FLOW  
Login and Upload any pdf and wait for the transactions to load on the left pane. To view the pdf, look to right pane.
